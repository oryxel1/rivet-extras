# Rivet Extras
This added some minor component and stuff that likely won't make it
in the mainstream version of [Rivet](https://github.com/Lenni0451/rivet)

## Current stuff
- Typing text (Label but with typing animation)
- Wheel color picker (color picker but round)
- button image (a button that is simply just an image)
- full slider (better than lenni's slider)
- number picker (just drag number input but have an text field when clicked on)
